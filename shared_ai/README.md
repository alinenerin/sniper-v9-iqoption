# Shared AI — camada consultiva comum

Será consultada pelos motores Forex e Binárias, sem executar ordens. Entrada: candles, mercado, símbolo, timeframe e contexto. Saída: consulta com anomalia, técnica, sentimento, previsão, probabilidade, vetos e explicação. Cada mercado mantém seus próprios pesos, expiração, payout e regras de execução.
